# Student Record Management System

## Description
This is a basic Student Record Management System developed using the C programming language.

It allows users to manage student details using a simple menu-driven program.

## Features
- Add student records
- View all student records
- Search student records using roll number
- Modify student details
- Delete student records
- Exit the program

## Technologies Used
- C Programming
- VS Code

## How to Run

1. Clone the repository.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Compile the program:

```bash
gcc Main.c -o student
```

5. Run the program:

```bash
./student
```

## Student Details
Each record contains:
- Roll Number
- Name
- Course
- CGPA
